# Farming-on-Brazil
Jogo desenvolvido como parte do trabalho final para a disciplina de Prog 3 na Universidade Federal de Santa Catarina :D

## Como funciona?
O jogo se ambienta em uma região de mata amazônica, típica região brasileira com variação de diferentes frutas a depender da estação do ano, que a princípio serão quatro:

 - Verão
 - Outono
 - Inverno
 - Primavera
